## Array Cardio Day 1

練習 JS 的陣列操作，有 `filter()`, `map()`, `sort()`, `reduce()` 等。

## Snippets

`filter()` 過濾符合條件的選項，並傳回陣列。

`map()` 傳回依條件組合的陣列。

`sort()` 用來排序，若比較 a, b，要 a 排在 b 前需傳回小於 0 的值，要 a 在 b 後，需回傳大於 0 的值。

`reduce()` 用於累加數值，第一個值存放累加的總和，第二個值為陣列內容，初始值則放在 callback 外。

`querySelectorAll('')` 取得的是 NodeList，想用陣列的方法要用 `Array.from()` 轉為陣列。
